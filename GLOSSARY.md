# Glossary

User-facing terms for this plugin (not implementation).

| Term | Definition |
| --- | --- |
| **TOC** | Table of contents: the list of headings in the active note, used to jump within the document. |
| **Outline** | Obsidian’s built-in heading list in the right sidebar; same heading set as the TOC, different presentation. |
| **Active heading** | The heading that best matches the user’s current position while scrolling or editing. |
| **Floating TOC** | A TOC panel that stays visible near the editor without opening the sidebar outline. |
| **TOC rail** | Collapsed TOC: a vertical stack of short lines indicating heading count and depth (Notion default view). |
| **TOC panel** | Expanded TOC on hover: rounded overlay listing heading titles for navigation. |
| **Pixel Banner** | Third-party Obsidian plugin (`pexels-banner`) that renders a top cover image on notes; affects vertical layout for this plugin. |
